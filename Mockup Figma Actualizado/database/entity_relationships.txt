┌─────────────────────────────────────────────────────────────────────────────────────┐
│                            FLUJO DE DATOS PRINCIPAL                                 │
└─────────────────────────────────────────────────────────────────────────────────────┘

1. REGISTRO → users (client/professional)
2. APLICACIÓN PROFESIONAL → professional_profiles + professional_documents
3. VERIFICACIÓN → verified_by (verifier user)
4. BÚSQUEDA → professional_profiles + service_categories + regions/communes
5. SOLICITUD → service_requests
6. PAGO → payments (MercadoPago)
7. SERVICIO → service_requests.status updates
8. CALIFICACIÓN → reviews
9. NOTIFICACIONES → notifications
10. AUDITORÍA → admin_logs

┌─────────────────────────────────────────────────────────────────────────────────────┐
│                              CARDINALIDADES                                         │
└─────────────────────────────────────────────────────────────────────────────────────┘

RELACIÓN                           CARDINALIDAD    DESCRIPCIÓN
────────────────────────────────────────────────────────────────────────────
regions ↔ communes                     1:N        Una región tiene muchas comunas
users ↔ professional_profiles          1:0..1     Un usuario puede ser profesional
users ↔ service_requests (client)      1:N        Un cliente hace muchas solicitudes
users ↔ service_requests (prof.)       1:N        Un profesional recibe muchas solicitudes
professional_profiles ↔ documents      1:N        Un profesional sube muchos documentos
professional_profiles ↔ schedules      1:N        Un profesional tiene muchos horarios
service_requests ↔ payments            1:1        Una solicitud tiene un pago
service_requests ↔ reviews             1:0..1     Una solicitud puede tener una reseña
users ↔ notifications                  1:N        Un usuario recibe muchas notificaciones
users ↔ reviews (reviewer)             1:N        Un cliente escribe muchas reseñas
users ↔ reviews (reviewed)             1:N        Un profesional recibe muchas reseñas
