# Stack Tecnológico - ServiHogar

## 🔧 TECNOLOGÍAS

### Backend
- **Python** - Lenguaje de programación
- **Django 4.2.25** - Framework web
- **Django REST Framework 3.16.1** - Framework API RESTful
- **PostgreSQL 16** - Sistema de base de datos relacional
- **JWT (JSON Web Tokens)** - Protocolo de autenticación

### Frontend
- **JavaScript/TypeScript 5.8.3** - Lenguajes de programación
- **React 19.1.1** - Librería para interfaces de usuario
- **React Router DOM 7.9.3** - Librería de routing
- **Tailwind CSS 4.1.14** - Framework CSS utility-first
- **HTML5/CSS3** - Lenguajes de marcado y estilos

### Base de Datos
- **PostgreSQL 16** - Sistema gestor de base de datos

### Protocolos y Estándares
- **REST API** - Arquitectura de servicios web
- **HTTP/HTTPS** - Protocolo de transferencia
- **JSON** - Formato de intercambio de datos
- **JWT** - Estándar de tokens de autenticación
